# WhatsApp Pay — Product Teardown

A substantially rebuilt Next.js recreation of the public WhatsApp Pay case-study page.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```

## Included
- Warm editorial layout and sticky section navigation
- Hero, UPI growth chart and market-share visualisation
- Regulatory timeline, merchant soundbox comparison, PhonePe timeline and unit-economics chain
- Four product bets with custom CSS product-flow mockups
- Closed-loop commerce flywheel and epilogue
- BhanuPrakash author identity, LinkedIn and email links
- Original supplied CTWA PRD in PDF and editable DOCX formats

The case-study narrative and figures follow the supplied reference webpage and uploaded PRD. They are not independently fact-checked in this implementation and should be verified before formal publication.
